# Coach workbench revision — 2026-10-17

The Watch=3D / Edit=plan split below is superseded by the owner's 2026-10-18
[direct 3D authoring decision](DIRECT_3D_WORKBENCH.md). Other invariants remain.

The owner's practical review rejected Arena's abstract counters and prose-heavy
flow. This revision is within the existing basketball animator and existing
publication authorization. No canonical migration, protocol or dependencies change.

## Decisions

- One shared procedural 3D half-court scene for the home demonstration and Watch.
  Warm hardwood, orange offense, ice-blue defense, numbered athlete geometry,
  a raised basket and ground shadows. Deep blue-green chrome, warm ivory type,
  existing licensed Oswald headlines. The court is the dominant visual, with
  restrained transport and concrete action captions rather than slogan panels.
- Watch / Edit is local presentation state. Watch projects the same deterministic
  playback; Edit uses the accurate plan view and existing accessible controls.
  No 3D interaction may mutate an interpolated frame. Forced colors uses plan.
- Examples opened from home start in Watch; guided tutorials start in Edit.
  Existing direct document URLs keep their authoring entry; mobile/read-only
  defaults to Watch. Existing records and original cues are never reseeded.
- A fine mouse/trackpad retains full desktop authoring even in a narrow window.
  Coarse phones/tablets keep their specified capabilities independently of CSS.
- A drawn action belongs to the actor under its starting pointer, with explicit
  feedback for an empty start or an invalid ball-holder action.
- Captions describe the outgoing transition, not the already-arrived pose:
  5 sets the screen; 1 drives while 5 rolls; 1 passes to 5; 5 receives near the rim.
  These captions apply only to the unchanged example formation, possession,
  adjacent action set and paths. Edited/archived/reordered/appended transitions
  use current action descriptions and neutral step labels; the original example
  never claims that a deleted movement still happens. Trainer cues are retained.
- Local autosave remains the durability model. File backup, room capabilities,
  readonly review, recovery and per-user undo remain available.

## Practical exercise / exit gates

Watch the example, understand its recipient and result, switch to Edit, move a
player, draw directly from another player, append a continuation, play, undo,
close/reopen, share a viewing copy and verify two-session collaboration. Run RU/EN,
compact fine-pointer desktop and actual touch emulation. Compare real screenshots
with the concept and check maximum-scene rendering, reduced motion, offline launch,
durability, license closure and deployment. This is a simulated trainer task,
not a claim of a field study with a coach. Network/VPN and manual review limits
remain explicit in the production verification document.
